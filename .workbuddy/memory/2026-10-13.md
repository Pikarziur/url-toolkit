# 2026-10-13 工作日志

## 修复：安卓端复制生成数据失败（网站侧 bug，非手机问题）
- 现象：iOS 能复制，安卓（多在 App 内置 WebView / 微信里打开）复制不了生成的秒杀肥料链接，且旧代码无条件弹「已复制」假成功。
- 根因：`src/App.vue` 的 `copy()` 降级分支用 `opacity:0` 隐藏文本框 + `execCommand`，安卓/微信 WebView 忽略隐藏框导致静默失败；成功提示无条件弹出。
- 改动（App.vue）：
  1. 抽出 `copyText()`：优先 `navigator.clipboard.writeText`（需 HTTPS 安全上下文），失败降级到「屏幕外但 opacity:1 可见 + 真选中」的 textarea + `execCommand`，返回布尔。
  2. `copy()` 仅真成功才置 `copied[key]=true` 并弹成功；失败调 `showManualCopy()` 弹已选中文本框供长按手动复制。
  3. `copyAddrInfo` / `copyAllAddrResults` 改为按 `copy()` 返回的布尔决定是否打勾，消除地址栏假 ✓。
- 验证：`npm run build` 通过（11 模块，6.51s，零报错）。
- 说明：若安卓仍在完全锁死的 WebView（连 execCommand 都禁），会走手动长按兜底，保证一定能复制到。
