# 2026-10-22 工作日志

## 修复：查禁拍搜索框手机端「清空」按钮挤占输入框
- 现象：手机（≤479px）输入店铺名后，「✕ 清空」按钮占住输入框位置，看不到输入内容。
- 根因（两处）：
  1. `.ban-search` 是 flex 行，输入框 `.ban-search-input` 没有 `flex:1` 撑开，而 `.ban-clear-btn` 是 `flex-shrink:0` 固定宽 → 窄屏输入框被挤没。
  2. `style.css` 手机断点（≤479px）里针对竖排的规则写的是 `.ban-search-wrap`，但模板实际 class 是 `.ban-search` → 死代码，从未生效。
- 改动（src/style.css）：
  1. `.ban-search-input` 加 `flex:1; min-width:0;` → 任意屏宽输入框都撑开可见。
  2. 手机断点规则选择器 `.ban-search-wrap` → `.ban-search`，使 ≤479px 时搜索框真正竖排：输入框整行 + 清空按钮整行在下，彻底不重叠。
- 验证：`npm run build` 通过（CSS 26.56kB / JS 106.06kB，6.41s，零报错）。
